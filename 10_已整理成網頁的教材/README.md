# 10_已整理成網頁的教材

這個資料夾用來保存「已經被 Codex 整理成網頁、題目或教學素材」的原始資料。

建議流程：

1. 老師先把新資料放在 `00_上傳給Codex的教材`。
2. Codex 使用資料製作或更新網頁。
3. 老師確認網頁完成後，再請 Codex 把已處理的原始資料移到本資料夾。

## 建議分類

可以依單元建立子資料夾，例如：

- `化學鍵`
- `元素週期表`
- `酸鹼中和`
- `反應速率`

## 注意

- 這裡保存的是原始資料的歸檔，不代表一定會公開在學生網頁上。
- 若檔案包含學生個資、成績、帳號密碼或私人授權資料，不應放入網站專案。
- 移動資料前，Codex 應先確認哪些檔案已經完成整理。
