# 00_上傳給Codex的教材

這個資料夾是給老師放原始教材用的。

以後若要我協助製作或更新互動網頁，可以把資料放在這裡，例如：

- PDF 講義
- Word 檔
- Google Docs 匯出的文件
- 題目圖片
- 實驗照片
- 學生練習題草稿
- NotebookLM 產生的文字稿
- YouTube 影片連結整理

## 建議命名方式

請盡量用「單元名稱_資料類型_日期」命名，例如：

- `化學鍵_講義_20260815.pdf`
- `元素週期表_題目圖片_20260815`
- `酸鹼中和_NotebookLM文字稿_20260815.docx`
- `反應速率_題目草稿_20260815.md`

## 使用方式

1. 把新資料放進這個資料夾。
2. 告訴 Codex 要做哪一個單元。
3. Codex 會讀取這裡的資料，再協助整理成網頁、題目、解析或教學內容。

## 注意

- 不要放學生個人資料、成績單、帳號密碼或私人授權資料。
- 如果圖片或 PDF 有版權限制，建議只放自己製作或可合法教學使用的版本。
- 原始教材會保留在這裡，網頁用的整理後資料會另外放到網站檔案中。
